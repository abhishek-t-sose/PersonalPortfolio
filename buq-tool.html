BUQ Insights

Drop a CSV of model parameters and predicted properties. This tool builds the same three views used in Sose et al., JCTC 2025 to inspect a parameter–property dataset: a corner plot with correlation heatmap, a Gaussian Process surrogate per output, and first-order Sobol sensitivity indices.

Runs entirely in your browser — nothing you drop here is uploaded anywhere. No sample data? load a synthetic example built to mirror the paper's parameter/property structure.

1Upload your data

Drag and drop a CSV here, or click to choose a file

.csv — one row per sample, one column per parameter or property

2Assign column roles

Mark each column as an input (a model parameter), an output (a predicted property), or ignore it.

3Results
Corner plot & heatmap
GPR surrogate
Sobol sensitivity

One RBF-kernel Gaussian Process is fit per output column against all selected inputs. R² is computed on the training data itself (a fit-quality check, not a held-out validation score).

First-order Sobol indices estimated by sampling each trained GP surrogate (Saltelli's method), mirroring Figure 5 of the paper — the share of each output's variance explained by each input parameter alone.

This is an approximate, browser-only reimplementation for exploring your own data quickly — not a substitute for the paper's full PSO + Bayesian ensemble-sampling pipeline. Treat the GP fits and Sobol indices here as a first look, not a validated result.
